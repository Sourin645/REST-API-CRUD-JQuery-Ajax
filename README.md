# REST-API-CRUD-JQuery-Ajax
A Student Registration System built using Spring Boot REST API, jQuery DataTable, and AJAX to perform CRUD operations. The project demonstrates creating, reading, updating, and deleting student records through RESTful APIs, with Postman used for API testing and validation.
